# 지역화폐와 소상공인 폐업 — 데이터 선별 문서

> 처음 보는 사람을 위한 안내서. 이 프로젝트가 "무엇을, 왜, 어떤 데이터로, 어떻게" 하는지와
> **선별된 각 데이터셋이 담고 있는 정보**를 이 문서 하나로 파악할 수 있게 정리했다.
> 최종 업데이트: 2026-07-28

---

## 1. 한 줄 요약

**"지역화폐(경기지역화폐·인천e음 같은 지역 전용 결제수단)가 많이 풀린 동네에서는 소상공인 가게가 덜 망했을까?"** 를 공공데이터로 검증하는 프로젝트.

## 2. 왜 이 질문인가

- 지역화폐는 대형마트·백화점에서는 못 쓰고 **연매출 30억 이하 소상공인 가게에서만** 쓸 수 있다. 즉 "소상공인 매출을 지역 안에 묶어두는" 정책이다.
- 경기도는 2019년부터 도 전체가 도입했고, 시군마다 **발행 규모·인센티브(충전 시 6~10% 추가 지급)가 다르며**, 2024년부터는 예산이 크게 축소됐다.
- 이 "지역마다·시기마다 다른 정책 강도"가 자연실험이 된다: 많이 풀린 곳과 적게 풀린 곳에서 가게 폐업률이 다르게 움직였는지 비교하면 정책 효과를 추정할 수 있다.

## 3. 전체 흐름 한 장 그림

```

        │                                   │
```

## 4. 선별된 데이터셋과 담고 있는 정보

역할이 같은 것끼리 묶어서 설명한다. ✅ = 파일 확보·컬럼 실측 완료, ○ = 컬럼 확인·파일 미확보.

### 그룹 A. "지역화폐가 얼마나·어떻게 풀렸나" — 처치(T) 데이터

지역화폐의 유통량을 서로 다른 해상도로 담은 세 데이터. 공통적으로 **지역 × 시간 단위의 집계 통계**이며(개인 거래내역 아님), 시군명을 시군구코드로 바꿔 붙인다.

**① 경기도 지역화폐 발행·이용 현황** ✅ — 본 분석의 처치 변수 원천
| 컬럼 | 담긴 정보 |
|---|---|
| 시군명 | 경기 31개 시군 |
| 기준년월 | YYYYMM (월 단위, 확보분은 2024.01~2026.04) |
| 월별신규가입자수(명) | 그 달 새로 카드를 만든 사람 수 |
| 월별충전액(백만원) | 그 달 주민들이 충전한(=산) 금액 → **처치 T** |
| 월별사용액(백만원) | 그 달 실제 결제된 금액 |

⚠ 2023년부터 금액 단위가 천원→백만원으로 변경, 2024년부터는 정책발행(재난지원금 등) 제외. 2019~2023년분은 별도 파일로 존재(미확보).

**② 경기도 지역화폐 연령별·성별 이용현황** ○ — "누가 쓰나"
| 컬럼 | 담긴 정보 |
|---|---|
| 기준연도 / 시군명 | **연 단위** 집계 (월 아님 주의) |
| 연령대 / 성별 | 10~80대·기타 / 남·여 |
| 결제건수·결제금액 | 해당 인구집단의 연간 결제 규모 |
| 결제취소건수·취소금액·1회평균결제금액 | 거래 특성 |

용도: 연령별 사용률 계산 → "유효 사용자 인구" 분모 구성, 이질성 분석.

**③ 인천e음 군구별 업종별 결제금액** ✅ — 경기도 밖 확장·비교용
| 컬럼 | 담긴 정보 |
|---|---|
| 일자 | 일 단위 |
| 지역 | "인천광역시 ○구" 형태 (파싱해서 군구 추출) |
| 업종별 금액 컬럼 8개 | 문화취미-영화관 / 숙박 / 약국 / 연료 / 유통업(편의점) / 일반휴게 / 학원 / 기타 — **업종이 컬럼으로 펼쳐진 wide 포맷** |
| 전체금액 | 합계 |

⚠ 월마다 별도 파일(2020.07~, 65개)이고 업종 컬럼 구성이 달라질 수 있어 long 포맷으로 변환해 사용. "기타"에는 모바일앱·배달앱 결제가 포함.

### 그룹 B. "가게가 살았나 죽었나" — 결과(Y) 데이터

개별 점포 단위 데이터. **사업자등록번호**가 공통 축이다.

**④ 경기 지역화폐 가맹점 현황 스냅샷 ×10** ✅ — 핵심 결과 데이터
특정 시점에 존재한 가맹점 전체 명단. 시점: 2020, 2021.12, 2022.12, 2023.02, 2023.12, 2024.10, 2025.08, 2025.10, 2026.02, 2026.03 (약 41만 행/개).
| 컬럼 | 담긴 정보 |
|---|---|
| 시군명 / 상호명 | 가게 위치(시군)와 이름 |
| 업종명(종목명) / 업종코드 | 운영사(코나아이) 자체 분류 410종, 앞 2자리가 대분류 |
| 소재지도로명·지번주소 / 우편번호 | 주소 |
| 위도 / 경도 | WGS84 좌표 (결측 ~1.7%) |
| **사업자등록번호** | 국세청 발급 10자리 — **스냅샷 간 시계열 추적 키** |
| 가맹점번호 | 운영사 발급 — ⚠ '22·'23·'26년 재발급되어 추적 키로 사용 금지 |
| 휴폐업상태(코드) / 폐업일자 | 01 계속 / 02 휴업 / 03 폐업 |
| 데이터기준일자 | 스냅샷 기준 시점 |

사용법: 연속된 두 스냅샷을 사업자번호로 비교 → 사라진 가게(소멸)와 새로 생긴 가게(신규)를 세어 폐업률·신규가맹률을 만든다. ⚠ 2020년판만 사업자번호가 없어 기준선은 2021.12.

**⑤ 국세청 사업자등록 상태조회 API** ○ — 폐업 판정의 공식 검증
사업자번호(1회 100건, 일 100만 건)를 넣으면 반환:
| 필드 | 담긴 정보 |
|---|---|
| b_stt / b_stt_cd | 계속(01) / 휴업(02) / 폐업(03) |
| **end_dt** | **폐업일자** — "스냅샷에서 사라짐 = 진짜 폐업인가"를 확정 |
| tax_type 등 | 과세유형(일반/간이/면세), 전환일 |

⚠ 말소된 옛 번호는 "등록되지 않은 사업자"로 반환됨.

**⑥ 소진공 상가(상권)정보** ○ — 가맹 여부와 무관한 "전체 가게 모집단"
전국 모든 상가의 분기별 명단(약 39개 컬럼): 상가업소번호, 상호명, 상권업종 대·중·소분류, **표준산업분류(KSIC)**, 시도~행정동·법정동 코드, 주소, 좌표. 가맹점 데이터와는 좌표+상호명 퍼지 매칭으로 연결. 용도: 폐업률의 분모를 "가맹점"이 아닌 "전체 점포"로 확장, KSIC 브리지.

**⑦ 공정위 가맹본부(프랜차이즈) 정보 API** ○ — 심화 분석용
가맹**본부(본사)**의 업체명, 대표자, 사업자번호(본사 것), 법인등록번호, 기업규모, 브랜드 수, 계열사 수. ⚠ 개별 가맹점주 사업자번호와는 직접 매칭 안 됨 — 브랜드(영업표지)명 목록을 받아 가맹점 **상호명과 매칭**해 프랜차이즈 여부를 식별. 용도: "지역화폐 효과가 독립점포 vs 프랜차이즈에서 다른가".

### 그룹 C. "비교 기준과 배경" — 대조·통제 데이터

**⑧ 경기도 카드 소비 데이터 (11개 시)** ○ — 지역화폐가 아닌 "일반 소비"의 대조군
| 컬럼 | 담긴 정보 |
|---|---|
| 기준년월일 / 시군구코드 / **행정동코드** | 일 단위, 행안부 8자리 동 코드 |
| 카드사_업종분류코드·대분류명·중분류명 | 카드사 자체 분류 (F09, Q02 …) |
| 시간대 / 요일 / 성별 / 연령별 | 소비 프로필 (코드값) |
| 매출금액 / 매출건수 | 민간 카드사 전체 매출 |

⚠ 과천·광명·수원·시흥·안산·안양·용인·이천·포천·하남·화성만 개방, 상업이용 금지 라이선스. 용도: "지역화폐 소비가 늘 때 전체 소비도 늘었나(순증 vs 대체)" 구분.

**⑨ 주민등록 인구 (연령별)** ○ — 처치 변수의 분모
시군 × 연령 구간 × 월별 인구. 카드 발급 가능 연령(**만 14세 이상**) 인구를 기본 분모로 "1인당 충전액"을 만들고, 전체/19세+/20~64세 분모로 강건성을 확인한다(영유아 등 사용 불가 인구 혼입 문제 대응).

### 그룹 D. 데이터를 잇는 "번역표" — 코드·브리지 테이블

- **시군구 코드표**: 시군명 텍스트 ↔ 시군구코드(법정동코드 앞 5자리, 예: 수원 41110). 경기 31개 검증 완료
- **행정동 코드표**: 행안부 8자리 ↔ 법정동 10자리 (통계청 7자리와는 다른 체계, 동 통폐합 이력 주의)
- **업종 브리지** ⚠ 유일한 미완성 고리: 가맹점 업종코드(410종) ↔ 카드사 분류 ↔ 인천 업종(8종) ↔ KSIC. 표준이 없어 1회 수작업 매핑 필요 (대분류 ~20개 수준)

## 5. 데이터를 잇는 열쇠(조인 키) — 검증 결과 요약

| 열쇠 | 무엇을 잇나 | 검증 결과 |
|---|---|---|
| **시군구코드** (5자리) | 모든 지역 단위 데이터 (①②③④⑧⑨) | 경기 31개 시군 100% 매칭 ✅ |
| **사업자등록번호** (10자리, 불변) | ④ 스냅샷 간 추적, ④↔⑤ | 스냅샷 간 82~99% 유지 ✅ |
| **행정동코드** (행안부 8자리) | ⑧ ↔ ⑥ ↔ ⑨ | 코드 체계 일치 확인 ✅ |
| 위도·경도 + 상호명 | ④ ↔ ⑥ (정확 키 부재) | 퍼지 매칭 필요 |
| **업종코드** | A그룹 ↔ B그룹의 업종 연결 | ⚠ 브리지 테이블 자작 필요 |

**중요한 발견**: '가맹점번호'는 2022·2023·2026년에 재발급되어 시계열 추적에 쓰면 안 된다(쓰면 "가게 전부가 폐업했다"는 엉터리 결과가 나온다 — 실제로 처음에 겪었다). **사업자등록번호가 유일하게 안정적인 추적 키**다.

## 6. 지금까지 확인된 사실

**데이터 품질 관련**
- 연율화 폐업률(정확히는 '가맹 소멸률')은 대부분 구간에서 10~24% — 국내 소상공인 통계와 정합적인 수준
- 2021→2022 구간만 45%로 튀는데, 김포·성남·시흥의 가맹점 관리체계 변경이 섞인 것 → 분석에서 제외하거나 별도 통제 필요
- 2020년판 스냅샷은 사업자번호가 없어 기준선은 2021-12부터

**파일럿 분석 결과 (아직 예비 단계)**
- 시군×구간 154개 관측치로 이중차분(시군 고정효과+구간 고정효과) 추정 시:
  - 충전액 ↑ → 폐업률: **효과 없음** (계수 ≈ 0)
  - 충전액 ↑ → 신규 가맹: 양(+)의 방향이나 통계적으로 유의하지 않음
- 처치 데이터가 2024년 이후뿐이라 구간 5개만 사용된 한계. 결론을 내릴 단계는 아님

## 7. 조심해야 할 함정 목록

1. **가맹점번호 ≠ 추적 키** (재발급 이력) — 사업자등록번호만 사용
2. "스냅샷에서 사라짐"은 폐업+가맹해지+행정변경의 합 → 국세청 API로 검증 예정
3. 발행·이용 데이터: 2023년부터 금액 단위가 천원→백만원으로 변경, 2024년부터 정책발행 제외 → 시계열 이을 때 보정 필수
4. 연령별·성별 이용현황은 월별이 아니라 **연 단위**
5. 인천e음 파일은 업종이 컬럼으로 펼쳐진 wide 포맷이고 월마다 컬럼이 다를 수 있음
6. 시군이 31개뿐 → 표준오차는 wild cluster bootstrap 필요
7. 상관≠인과: 충전액이 많은 곳은 애초에 상권이 다름 → 고정효과·이벤트 스터디·업종 삼중차분으로 방어

### 용어 미니 사전
- **처치(T)**: 효과를 알고 싶은 정책 변수 — 여기서는 지역화폐 충전액
- **결과(Y)**: 정책이 영향을 줬을 변수 — 여기서는 폐업률·신규가맹률
- **패널 데이터**: 같은 대상(시군×업종)을 여러 시점 관찰한 표
- **이중차분(DID)**: "정책 많이 받은 곳의 전후 변화"에서 "적게 받은 곳의 전후 변화"를 빼서 효과를 추정하는 방법
- **스냅샷 차분**: 시점별 명단을 비교해 사라진 가게(폐업)와 새로 생긴 가게(개업)를 세는 것
- **연율화**: 길이가 다른 구간(3개월, 11개월…)의 비율을 "1년 기준"으로 환산해 비교 가능하게 만드는 것
