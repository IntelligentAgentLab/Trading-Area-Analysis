## 2. 파일 여는 법

### 압축을 풀지 않고 바로 읽기 (권장)

```python
import pandas as pd

# .gz는 pandas가 알아서 풀어서 읽습니다
df = pd.read_csv("가맹점스냅샷/가맹점_20260331.csv.gz", encoding="cp949", low_memory=False)

# 2025-10-31만 엑셀
df_2510 = pd.read_excel("가맹점스냅샷/가맹점_20251031.xlsx")
```

### 압축 풀어서 쓰기

```bash
# Git Bash / macOS / Linux
gunzip -k 가맹점스냅샷/가맹점_20260331.csv.gz     # -k = 원본 gz 유지
```
Windows 탐색기에서는 **반디집·알집·7-Zip** 으로 우클릭 → 압축 풀기.

### ⚠️ 인코딩 주의

CSV는 전부 **cp949(euc-kr)** 입니다.
- 파이썬: `encoding="cp949"` 를 반드시 지정 (안 하면 `UnicodeDecodeError`)
- 엑셀: 그냥 열면 정상. VS Code에서 깨져 보이면 인코딩을 EUC-KR로 변경

## 3. 데이터 쓸 때 꼭 알아야 할 것 3가지

1. **시계열 추적은 `사업자등록번호`로만** — `가맹점번호`는 2022·2023·2026년에 운영사가 재발급해서, 이걸로 스냅샷을 비교하면 "가게가 전부 폐업했다"는 엉터리 결과가 나옵니다.
2. **`가맹점_2020`에는 사업자등록번호 컬럼이 없습니다** — 그래서 시계열 분석의 기준선은 2021-12부터입니다.
3. **성남·김포·시흥은 가맹점을 별도 관리**해서 일부 스냅샷에 데이터가 통째로 빠져 있습니다. 시흥시는 사업자등록번호가 `T`로 시작하는 노점상이 섞여 있어, 숫자 10자리로 필터링하면 시 전체가 사라집니다. **집계 전에 시군별 행 수를 반드시 확인하세요.**
